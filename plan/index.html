해밀턴 밀 세탁 라스트마일 서비스

해밀턴 밀 단지(Dacula/Buford, Gwinnett County, GA) 주민의 빨래·드라이클리닝·이불을 정해진 요일에 문 앞에서 픽업해 제휴 세탁소에 맡기고, 끝나면 다시 배달한다.

01한 줄 요약

우리는 세탁을 하지 않는다. 배달 · 일정 · 투명한 진행 상황 · 고객 관계가 우리의 제품이다.

02핵심 가설과 포지셔닝

빈자리: "빨래 + 드라이클리닝 + 큰 품목을 한 번에, 정해진 요일·시간에, 동네 업체가" 해주는 서비스가 없다.
  • Poplin — 빨래(wash & fold)만, $1/lb, 드라이클리닝 없음, 정확한 시간 지정 불가.
  • 단지 주변 드라이클리너 — 대부분 매장 방문형, 픽업 없음.

마진의 원천

한 번 방문에 여러 서비스를 묶는 것(바구니 크기) + 경로 밀도(한 번 돌 때 몇 집).

하지 말 것

빨래 단독으로 Poplin과 가격 경쟁.

브랜드 메시지

세탁 전반. 첫 마케팅 훅은 "이불·드라이클리닝을 문 앞에서".

고객 관계의 실체

품질 책임을 우리가 진다 — 픽업 사진, 품목 기록, 분실·손상 보상 정책.

06운영 원칙

  • 픽업은 단지 구역별 고정 요일(예: 화/금) + 시간대. 마감 시간 운영.
  • 파트너 매장 왕복은 하루 1회로 묶음.
  • 픽업 시 봉투 태그 + 사진, 드라이클리닝은 품목 수 기록.
  • 처리 기간 약속(SLA): 드라이클리닝 48h 목표, 빨래 24–48h.
  • 책임: 세탁 중 손상 = 파트너, 운송 중 분실 = 우리. 계약서 명시.
  • 초기엔 Han이 직접 배달하며 숫자 실측.

07앱 MVP 스펙

  • 공급자 연동 없음. 상태 업데이트는 내부 관리 화면에서 Han이 직접.
  • 네이티브 앱 대신 모바일 웹앱(PWA)으로 시작 — 링크로 단지 커뮤니티에 바로 배포.

고객 화면

  1. 가격표 — 빨래/lb, 드라이 품목별, 큰 품목 정액, 배달비 규칙
  2. 예약 — 주소 → 서비스 지역 검사(밖이면 대기 명단), 고정 요일·시간대 슬롯, 서비스 종류, 메모
  3. 진행 상황 타임라인 — 상태별 시각 + 픽업/배달 사진
  4. 결제 — 카드 등록, 무게·품목 확정 후 청구 (구독은 2단계)
  5. 알림 — 상태 변경 시 SMS

내부 관리 화면 (Han용)

  • 오늘의 픽업/배달 목록 (경로 순서)
  • 주문별 상태 변경, 사진 업로드, 무게·품목·금액 입력
  • 파트너별 입고/출고 묶음 기록, 주간 정산 합계
